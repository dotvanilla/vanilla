如何在本机打开这个页面？

wasm 通过 fetch 加载，因此需要用 HTTP 方式打开（file:// 会被浏览器的同源策略拦截）：
cd <repo>/test/base64 && python -m http.server 8080
然后访问 http://localhost:8080/index.html。
若 base64.wasm 不存在，先执行：
vanilla.exe test/base64/base64.vbproj /out test/base64/base64.wasm
